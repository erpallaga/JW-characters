¿Cómo quieres navegar las flashcards?

Elige el estilo de la pantalla principal de repaso

A

Mazo (una carta a la vez)

Como flashcards físicas: una carta grande centrada, botones ← Anterior / Siguiente →, clic para voltear. Estilo clásico de estudio, enfocado, sin distracción.

B

Cuadrícula (todas visibles)

Grid de tarjetas pequeñas, cada una se voltea al hacer clic individualmente. Ves todo el catálogo de un vistazo, útil para elegir un personaje directamente.

C

Ambos: cuadrícula + modo mazo

Cuadrícula como pantalla principal, con botón "Modo estudio" que entra al mazo secuencial de una carta a la vez.
